# bimonatools 共通仕様書

このドキュメントは、bimonatoolsとして配布する全アプリに共通する方針をまとめたもの。
新しい決定事項が出たら、その都度このファイルを更新する。
個別アプリ固有の仕様は `app-<アプリ名>.md` に分けて書く。

## ブランド

- 屋号: bimonatools
- 由来: 飼っている3匹のペット(ビリー・モコ・ナツ)の名前から
- ポートフォリオサイト: https://bimo72.github.io/bimonatools/(GitHub Pagesで公開)
- アプリ一覧は `apps.json` を編集するだけで反映される仕組み

## 配布・販売の基本方針

- まずは無料で配布し、需要を確認してから機能を作り込んで有料版をリリースする(フリーミアム的な段階展開)
- 配布・メール収集の窓口は BOOTH を使う
- ドメイン・サーバーなど固定費がかかるものは、需要が確認できるまで極力かけない

## ユーザー情報の収集方針

- 匿名利用ではなく、**Googleアカウントでのログインを必須**にする
  - GASの公開設定: 「アクセスできるユーザー」を `Googleアカウントを持つ全員` にする
  - `Session.getActiveUser().getEmail()` でメールアドレスを取得する
- 収集する情報は必要最小限にする
  - **メールアドレス**
  - **利用日時**(いつ使われたか)
  - 年齢・性別・職業・居住地域などの属性情報は、明確な利用目的が決まるまでは収集しない
- アンケートは**利用後に必ず表示する**共通機能として、全アプリから呼び出せるようにする(表示は必須、回答自体は任意)
  - 各アプリは処理完了後、共通のアンケート画面(またはフォーム)を必ず表示する
  - 回答された場合のみ、メールアドレスと紐づけて利用履歴と突き合わせられるようにする
  - フォームのURLに `?email=` パラメータを付け、取得済みのメールアドレスを事前入力させる方法を使う

## データ保管

- 利用履歴・アンケート回答は、**アプリ横断の共通スプレッドシート**にまとめて記録する(アプリごとに分けない)
- 記録する列には `email`・`利用日時`・**`アプリ名`**を含め、どのアプリのログ/回答かを区別できるようにする
- スプレッドシートへのアクセス権限は必要最小限に絞る

## プライバシーポリシー

- メールアドレス・利用日時・任意アンケート回答を収集する以上、収集項目と利用目的を明記したプライバシーポリシーを用意する
- 個人開発であっても個人情報取扱事業者に該当するため、利用目的の公表・安全管理措置が必要
- ポートフォリオサイト(GitHub Pages)内に1ページとして設置する想定

## 開発環境

- 個人開発は Claude Code + clasp(GAS用CLI)を使い、Windows環境で行う
- チャット(claude.ai)側では方針の相談・決定を行い、決定事項はこのファイルに反映する
- Claude Code側では、このファイル(`docs/common-spec.md`)を実装時の一次情報として参照する
